Their licenses belong to their respective authors. None of the package source code is
included in this repository by default.

- [M5Unified](https://github.com/m5stack/M5Unified), pinned v0.3.0 (MIT; M5Stack)
- [M5GFX](https://github.com/m5stack/M5GFX), pinned v0.3.0 (MIT; M5Stack)
- [M5PM1](https://github.com/m5stack/M5PM1), pinned v1.0.7 (consult upstream license)
- [M5IOE1](https://github.com/m5stack/M5IOE1), pinned v1.0.9 (consult upstream license)
- [PlatformIO](https://platformio.org/) and [Espressif Arduino core](https://github.com/espressif/arduino-esp32) (external toolchain / dependencies)

The MIT license in `LICENSE` applies only to original code here; it does not override
external dependencies' license terms or the artwork/audio rights described in `ASSET_LICENSE.md`.
